# Security policy

CFOKit holds a company's books, so a vulnerability can expose financial records. Please report one
privately, never in a public issue, pull request or discussion.

## Reporting a vulnerability

Email **[security contact to add]** with:

- what you found, and where (file, endpoint or tool)
- how to reproduce it
- what an attacker could do with it

You'll get a reply acknowledging the report. Please give the maintainers a reasonable chance to fix
it before you disclose it publicly.

## Supported versions

CFOKit is early software with no tagged release yet. Only the `main` branch gets security fixes.
